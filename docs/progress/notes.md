# 功能進度紀錄：便條紙節點無限畫布與群組切換 (Notes Infinite Canvas & Group Switching)

- **紀錄時間**：2026-09-18
- **當前目標與背景**：
  為根本解決傳統網格清單「垂直排版極吃空間、卡片拉大後互相擠壓」的痛點，便條紙（Notes）模組正式升級為**「節點式無限畫布 ＋ 分區群組切換顯示」**架構。採用現代視覺化白板（如 FigJam / Obsidian Canvas）的 2D 自由佈局思維，結合無級平移縮放、分區群組框、群組收合堆疊與頂部膠囊鏡頭瞬移定位，同時保留傳統清單網格雙向切換，徹底兼顧空間利用率與檢索靈活性。

---

## 已完成事項清單（功能現況）

- [x] **雙檢視架構 (Dual-View Architecture)**：
  - 工具列提供「🔲 畫布模式」與「📋 清單模式」切換膠囊，使用者偏好自動持久化於 `localStorage`。
  - 兩種模式共用底層 `Storage` 資料中心，新增、編輯、刪除即時雙向同步。
- [x] **節點式無限畫布引擎 (Infinite Canvas Engine)**：
  - **平滑無級縮放 (Zoom)**：滑鼠滾輪以指標為錨點於 `0.2x` ~ `2.0x` 間自由縮放，支援一鍵「🔍 100%」重設視角。
  - **自由平移 (Pan)**：滑鼠中鍵、右鍵或按住 `空白鍵 (Space)` 拖動畫布背景進行平移。
  - **點陣網格背景**：現代科技感暗色微格線（`radial-gradient` 點陣），營造沉浸式白板空間。
- [x] **分區群組框與空間釋放機制 (Group Frames & Space Saving)**：
  - 每個分類在畫布上呈現為具備半透明毛玻璃質感、邊框微光的「群組外框（Group Frame）」。
  - 拖動群組頂部標題列即可整組搬移內部所有便條節點。
  - **群組收合堆疊 (Group Collapse)**：點擊群組框右上角「－ / ＋」按鈕，群組瞬間收合為小巧徽章卡片，隱藏內部便籤並釋放龐大畫布空間；狀態儲存於 `cat.collapsed`。
- [x] **頂部群組導航膠囊與鏡頭聚焦 (Group Switcher & Pan-to-Group)**：
  - 頂部工具列即時渲染各分類之標籤膠囊（顯示名稱與便條數量）。
  - 點擊任一群組膠囊時，畫布鏡頭（Camera）自動計算該群組邊界並平滑平移聚焦至中央，附帶藍色呼吸燈高亮動畫（Focus Pulse）。
- [x] **智慧自動排版 (Auto Layout Algorithm)**：
  - 提供「📐 自動排版」按鈕，自動將所有分類群組橫向排列，群組內部便條依最佳欄數（1~3 欄）整齊網格堆疊，初次載入或缺少座標時自動適配。
- [x] **便條節點互動與就地編輯 (Sticky Node Interactions)**：
  - **雙擊行內就地直接編輯**：連點兩下卡片直接就地切換文字框，支援 `Ctrl+Enter` 儲存、`Esc` 取消、點擊外部自動儲存。
  - **一鍵複製全文**：卡片標題列內建「📋」按鈕，點擊後寫入剪貼簿並彈出浮動 Toast 提示。
  - **智慧深淺色文字反色**：內建 YIQ 色彩明度運算，深色卡片套用純白字體與高反差連結，淺色卡片維持深黑文字。
  - **便條自由拖曳**：在群組內部按住卡片頂部可任意拖曳擺放，接近邊界時自動延展群組框尺寸。

## 待辦事項 / 後續優化規劃 (Roadmap)

### 第一階段：進階畫布視覺與輔助線
- [ ] **群組顏色標籤**：允許為整個群組外框自訂主題色邊框（如藍色代表伺服器、黃色代表會議）。
- [ ] **連線關係圖 (Node Linking)**：支援在關聯便條節點之間手動拉出貝茲曲線箭頭（如「VPN 帳密」指向「API 端點」）。

### 第二階段：首頁與跨模組連動
- [ ] **首頁儀表板置頂便條小工具 (Dashboard Pinned Notes)**：將釘選的便條同步顯示於首頁工作台。
- [ ] **便條一鍵轉為待辦任務 (Convert to Task)**：便條若記錄代辦項目，支援一鍵轉存入 `tasks.html`。
