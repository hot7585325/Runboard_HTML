# 紀錄時間：2026-09-11

## 當前目標與背景
開發「通用檔案過濾編輯器 (Smart Editor)」，取代原先單一的 Log 分析器。
目標是在保持「本機端、無伺服器 (Serverless)」的前提下，透過引入 CDN 擴展功能，實現對多種檔案格式（`.txt`, `.md`, `.csv`, `.json`, `.xlsx`, `.docx`）的讀取、編輯與過濾能力，打造出類似輕量級本機 IDE 的體驗。

## 已完成事項清單
- [x] 整合 **CodeMirror**，實現純文字與程式碼的語法高亮、以及覆寫本機檔案的編輯功能。
- [x] 整合 **Marked.js**，實現 Markdown (`.md`) 的即時 HTML 渲染與雙模式切換。
- [x] 整合 **SheetJS**，實現 Excel (`.xlsx`) 二進位檔案的唯讀表格預覽。
- [x] 整合 **Mammoth.js**，實現 Word (`.docx`) 二進位檔案的唯讀網頁預覽。
- [x] 實作右側**「過濾引擎 (Filter Engine)」**，支援 Regex，可即時萃取符合關鍵字的文字行或資料列，並支援點擊跳轉行號。
- [x] 清除並刪除舊版的 `log_viewer` 相關程式碼與樣式。
- [x] 更新 `js/nav.js`，將工具註冊於側邊導覽列。

## 待辦事項 / 已知問題
- 暫無重大 Bug，核心讀寫功能運作正常。
- **[效能限制]** 因受限於純前端架構，若載入極端巨大檔案 (如數百 MB 的 Log)，全量載入與正則比對可能會導致瀏覽器卡頓。未來若有效能瓶頸，可考慮升級為 Chunk 分塊讀取或導入 Web Worker 處理。

## 核心檔案對照表
- `smart_editor.html`：工具主畫面介面，並集中管理所有 CDN 的引入。
- `css/smart_editor.css`：實作左 (70%) 右 (30%) 分割視窗、預覽區塊及過濾清單樣式。
- `js/smart_editor.js`：核心邏輯（包含 File System API、副檔名路由系統、過濾引擎）。
- `js/nav.js`：全域導覽列註冊處。
